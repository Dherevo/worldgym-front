# Purpose
How to created the layout for component using our components and our standards. The code must follow our guidelines to build the HTML of pages.

We use Prime UI components (PrimeVue, PrimeReact, PrimeNG). Upon Prime we also use some of our components which are found in /lib/src/widgets. These are explained in the following sections.

If you don't find specific information about our component, please at least use Prime's.

Never use tailwind or any other css library in html. Use only the css explained here.

We don't use Vue composition or options API. We use vue-facing-decorator to work with class components.
